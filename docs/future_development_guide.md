## 一、 梯级水电建模与数据补充

针对三峡-葛洲坝等强耦合水电群，未来若需从现有的“流域宏观控水”升级为“梯级水电联合调度”，其核心是解耦**“水利拓扑”**（水量流向关系）与**“电网拓扑”**（电量注入关系）。

### 1. 需补充的数据清单
若要实现梯级水电模型，必须在原始数据库中补充以下水文与物理参数：
- **拓扑与延迟**：
  - `upstream_hydro_id` / `downstream_hydro_id`：上下游机组连接关系。
  - `water_delay` (h)：水流从上游流到下游的时间延迟。
- **水库库容**：
  - `v_max` / `v_min` (万 $\text{m}^3$)：最大库容与死库容。
  - `v_init` / `v_end` (万 $\text{m}^3$)：调度期初的初始蓄水量与期末的目标蓄水量。
- **流量与效率**：
  - `q_power_max` ($\text{m}^3/\text{s}$ 或万 $\text{m}^3/\text{h}$)：最大发电流量。
  - `water_to_power_coef` ($\text{MW} / (\text{m}^3/\text{s})$)：水-电转换系数 $\eta$。
- **天然来水**：
  - `natural_inflow` (时序向量)：各时刻区间天然径流流量。

### 2. 数学物理模型
对于每个电站 $i$，在时刻 $t$ 引入库容 $V_{i,t}$、发电流量 $Q^{\text{发电}}_{i,t}$、弃水流量 $Q^{\text{弃水}}_{i,t}$ 作为决策变量，建立如下约束：

- **水量平衡时序递推**：
  $$V_{i,t} = V_{i,t-1} + \left( I_{i,t} + \sum_{j \in Up(i)} \left( Q^{\text{发电}}_{j, t - \tau_{ji}} + Q^{\text{弃水}}_{j, t - \tau_{ji}} \right) - Q^{\text{发电}}_{i,t} - Q^{\text{弃水}}_{i,t} \right) \Delta t$$
- **水-电转换关系**：
  $$P_{i,t} = \eta_i \cdot Q^{\text{发电}}_{i,t}$$
- **物理边界控制**：
  $$V_{i,\min} \le V_{i,t} \le V_{i,\max}$$
  $$0 \le Q^{\text{发电}}_{i,t} \le Q^{\text{发电}}_{i,\max}$$
- **期末库容控制**（防止周期末把水放光）：
  $$V_{i, T} \ge V_{i, \text{end}}$$
